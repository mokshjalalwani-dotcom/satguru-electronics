# Satguru Electronics — AI-Powered Retail Automation

> Earlier iteration of the SatguruShop platform with AI service integrations and admin automation for Satguru Electricals.

## Overview

The predecessor to SatguruShop — a TypeScript-based retail automation platform that introduced AI features like smart inventory alerts, automated reporting, and a Python FastAPI AI microservice.

## Tech Stack

| Layer | Technology |
|---|---|
| Frontend | React + TypeScript + Tailwind CSS |
| Backend | Node.js + Express |
| AI Service | Python FastAPI |
| Database | MongoDB |
| Deployment | Render (Singapore) |

## Architecture

`
satguru-electronics/
├── admin-portal/    # Vite + React + TypeScript admin UI
├── backend-api/     # Node.js REST API
├── ai-service/      # Python FastAPI AI microservice
└── server.js        # Root Express server
`

## Note

This repo is the version Render.com is connected to for deployment. Active development has moved to [SatguruShop](https://github.com/mokshjalalwani-dotcom/SatguruShop).
